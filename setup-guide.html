Step 3 of 8
4
Add Your API Key to .env
Paste your key into the config file so the server can use it.
💡
The .env file is hidden by default on Mac. Press Cmd + Shift + . inside the folder to reveal hidden files.
💡
In File Explorer: click View tab at top → check "Hidden items" checkbox to see the .env file.
.env
# Required — paste your key below
ANTHROPIC_API_KEY=sk-ant-api03-your-actual-key-here
# Optional — for real Indeed results
SERPAPI_KEY=your_serpapi_key_here
1
Open the job-agent-real folder
2
Show hidden files (see tip above)
3
Open .env with any text editor
Notepad (Windows) or TextEdit (Mac) both work fine
4
Replace the placeholder with your real key
Delete your_anthropic_key_here and paste your key
5
Save the file
Mac: Cmd+S    Windows: Ctrl+S

Step 5 of 8
6
Install Dependencies
Download the packages the app needs. Do this only once.
Type this command in your terminal and press Enter:
npm install
Terminal — job-agent-real
$ npm install
npm warn deprecated...
added 127 packages in 28s
▸ 42 packages are looking for funding
✓ Done!
$
💡
Lots of text scrolling? That's completely normal. npm is downloading packages. Wait until you see the $ prompt again before continuing.
⚠️
Error: "command not found"? Node.js wasn't installed correctly. Go back to Step 1 and reinstall.
Step 6 of 8
7
Start the Server
Launch the backend. Keep this terminal window open while using the app.
In the same terminal, type this and press Enter:
node server.js
Terminal — job-agent-real
$ node server.js
✅ JobAgent server running at http://localhost:3001
ANTHROPIC_API_KEY: ✓ set
SERPAPI_KEY: ✗ not set (using mock jobs)
Open job-agent.html in your browser.
✅
You should see the green checkmark! If ANTHROPIC_API_KEY shows ✓ set, everything is working.
⚠️
ANTHROPIC_API_KEY shows ✗ missing? Go back to Step 4 and make sure you saved the .env file correctly.
🔒
Keep this terminal open! The server only runs while this window is open. Don't close it while using the app.
